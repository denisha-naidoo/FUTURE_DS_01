# Superstore Sales Dashboard

## Overview
An interactive Power BI dashboard analyzing Superstore sales data, providing insights into revenue, profit, and sales trends across regions, categories, and customer segments.

## Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)

## Key Insights
- Sales and profit performance by region and category
- Top-performing products and customer segments
- Year-over-year trend analysis

## How to View
1. Download the `.pbix` file
2. Open with [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free)
